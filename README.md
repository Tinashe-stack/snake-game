# Snake Game

A simple Snake game built with Python's `turtle` module.

## Features
- Classic snake movement with arrow keys
- Food collision detection
- Snake growth after eating food
- Wall and tail collision reset
- High score saved between runs

## Files
- `main.py` - game loop and collision handling
- `snake.py` - snake class and movement logic
- `food.py` - food spawning
- `scoreboard.py` - score and high score display
- `data.txt` - stores the high score

## How to run
1. Make sure Python 3 is installed
2. Download or clone this repository
3. Run:

```bash
python main.py
